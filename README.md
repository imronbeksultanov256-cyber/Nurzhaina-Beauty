# NURZHANA BEAUTY — сайт бренда

Аппаратная косметология · Бишкек · Омоложение без операций

Статический сайт без сборщиков и зависимостей: чистые HTML, CSS и JavaScript.
Открывается локально, заливается на любой хостинг (Netlify, Vercel, GitHub Pages, обычный shared-хостинг) простым копированием папки.

---

## Запуск локально

```bash
python -m http.server 4173
```

Затем откройте http://localhost:4173

## Что нужно добавить

### 1. Логотип — готово

Оригинал лежит в `assets/img/logo.png` и не изменяется.
Из него сгенерированы рабочие варианты с прозрачным фоном:

| файл | где используется |
|---|---|
| `logo-mark.png` | монограмма NB — шапка сайта |
| `logo-mark-light.png` | монограмма для тёмного фона |
| `logo-full.png` | полный логотип для светлого фона |
| `logo-full-light.png` | полный логотип — подвал |
| `favicon-32.png`, `apple-touch-icon.png` | иконки вкладки и iOS |
| `og.jpg` | картинка для соцсетей 1200×630 |

В шапке стоит монограмма из оригинала плюс подпись `NURZHANA BEAUTY`, набранная фирменным шрифтом:
полный логотип — вертикальный, и в узкой шапке подпись внутри него была бы высотой около 4 px.
В подвале и в картинке для соцсетей используется оригинальный логотип целиком, без изменений.

Если замените оригинал на другой файл — перегенерируйте производные:

```bash
python tools/make-logo-assets.py
```

Скрипт сам находит границы монограммы и подписи, убирает белый фон и пересобирает иконки и OG-картинку.

### 2. Фотографии

Сейчас на месте всех фото — аккуратные плейсхолдеры в фирменных тонах.
Ненастоящих фото «до / после», лиц и стоковых картинок на сайте намеренно нет.

Чтобы поставить настоящее фото, замените блок

```html
<div class="ph"><span class="ph__label">Фото</span></div>
```

на

```html
<img src="assets/img/photo-1.webp" alt="Описание фотографии" loading="lazy" decoding="async">
```

Кадрирование, скругления и пропорции подхватятся сами — за это отвечает родительский `.ratio`.

Стиль съёмки: естественный дневной свет, ivory / beige / nude, натуральная текстура кожи, без тяжёлой ретуши.
Формат: WebP или AVIF, ширина 1600–2000 px для крупных блоков, 800–1000 px для карточек.

### 3. Цены

Откройте `assets/js/data.js` → массив `PROCEDURES`.
У каждой позиции есть `duration` и `price`. Пока там `null` — сайт показывает «Уточняется» и «По запросу».

```js
duration: '60 мин',
price: '5 000 сом',
```

Полноценные позиции прайса добавляются в `price.html` — структура строки уже готова, достаточно скопировать блок `.price-row`.

### 4. Адрес и карта

Адрес нигде не выдуман. Когда он появится:

1. в `assets/js/data.js` заполните `CONTACTS.address`;
2. в `contacts.html` замените блок `.map-slot` на iframe Google Maps или 2GIS;
3. добавьте адрес в JSON-LD (`"streetAddress"`) в `<head>` файлов `index.html` и `contacts.html`.

### 5. Форма записи

По умолчанию форма собирает данные и открывает WhatsApp с уже готовым сообщением — это работает без сервера.

Если нужен приём заявок на почту или в CRM, укажите адрес обработчика в `assets/js/data.js`:

```js
const FORM_ENDPOINT = 'https://formspree.io/f/xxxxxxx';
```

Тогда заявка уйдёт POST-запросом (JSON), а WhatsApp останется запасным вариантом при ошибке сети.

### 6. Видео

Слоты рассчитаны на вертикальные видео 9:16 (как Reels) и горизонтальные 16:9.
Замените блок `.ph--ink` внутри `.ratio` на `<video src="…" poster="…" playsinline controls>`
или на `<iframe src="https://www.instagram.com/reel/XXXX/embed">`.

## Редактирование шапки и подвала

Шапка и подвал лежат в `_partials/` и продублированы во все страницы (так быстрее грузится и лучше для SEO).

После правки `_partials/header.html` или `_partials/footer.html` выполните:

```bash
bash build.sh
```

Скрипт можно запускать сколько угодно раз — он идемпотентный.

## Что уже сделано

- 10 страниц с единой визуальной системой
- Sticky-шапка, мобильное меню, нижняя панель `WhatsApp | Записаться | Instagram`

- Анимации появления, image reveal, мягкий параллакс; всё отключается при `prefers-reduced-motion`
- Полноэкранный просмотр галереи и видео с навигацией стрелками и клавиатурой
- Фильтры в прайсе и в галерее результатов
- Форма записи с состоянием «Спасибо»
- SEO: уникальные title/description, Open Graph, favicon, JSON-LD, alt-тексты, по одному H1 на страницу
- Доступность: skip-link, focus-states, aria-атрибуты, навигация с клавиатуры
- Проверено: нет горизонтального скролла на 375 / 768 / 1280 px
